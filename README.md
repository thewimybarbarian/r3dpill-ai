# R3DPILL AI

**Landing page for an AI studio**: dark, cinematic, and motion-heavy.

**Live:** https://r3dpill-ai.vercel.app

## Highlights

- Animated hero with background video
- Custom SVG circuit-line animations
- Interactive "pill gauge" component

## Stack

Next.js · TypeScript · Tailwind CSS · Vercel

## Run locally

```bash
npm install
npm run dev
```
